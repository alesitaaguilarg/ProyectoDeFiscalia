# Presentación del Avance

Esta carpeta reúne el material audiovisual y de soporte empleado para exponer la evolución del proyecto **SEDFGEY** entre la primera y la segunda entrega.

## Criterios de la Presentación
* **Duración y Ritmo:** Exposición estructurada y ajustada al límite de **5 minutos**, con flujo lógico sobre el avance del producto.
* **Calidad Visual y Auditiva:** Uso de diapositivas balanceadas, diagramas legibles, consistencia visual y audio uniforme.
* **Lenguaje Técnico:** Empleo preciso de la terminología de Ingeniería de Software y Programación Orientada a Objetos.
