# Competencias Desarrolladas

En esta sección se documenta y argumenta cómo las actividades técnicas y colaborativas realizadas durante el desarrollo de **SEDFGEY** promueven las competencias del perfil de Ingeniería de Software.

## Contenido

| Categoría | Descripción del Enfoque |
| :--- | :--- |
| **Competencias Genéricas** | Argumentación de habilidades transversales (trabajo colaborativo mediante Git/GitHub, comunicación efectiva, autogestión, resolución de problemas y cumplimiento de plazos) evidenciadas en el proyecto. |
| **Competencias Específicas** | Argumentación de habilidades técnicas de Ingeniería de Software (análisis y refinamiento de requisitos, modelado orientado a objetos en UML, aplicación del patrón MVC y gestión de versiones) aplicadas al producto. |
