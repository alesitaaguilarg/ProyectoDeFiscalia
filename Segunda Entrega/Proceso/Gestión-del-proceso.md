# Bitácoras de Reuniones

## Herramientas de monitoreo y seguimiento

| Herramienta | Para qué se usó |
| :--- | :--- |
| **Grupo de mensajería del equipo** | Canal de todas las reuniones: acuerdos, dudas, revisión de avances y recordatorios de entrega. |
| **GitHub Issues (`ProyectoDeFiscalia`)** | Cada actividad de los sprints tiene su issue con responsable asignado, de modo que se ve qué está pendiente y qué ya se cerró. |
| **Ramas (branches) y pull requests** | Cada integrante trabajó en su rama y los cambios se integraron por pull request. |
| **Descripción del proceso (`Descripción-del-proceso.md`)** | Planeación y seguimiento de los 4 sprints: actividades, responsables y entregables. |
| **Bitácoras de reuniones (`Gestión-del-proceso.md`)** | Registro de acuerdos, resolución de conflictos, tareas, responsables y productos de cada sprint. |
