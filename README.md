# Sistema de Evaluación del Desempeño de la Fiscalía General del Estado de Yucatán (SEDFGEY)

## Equipo 4 - Programación Orientada a Objetos

## Tercera Entrega

### Descripción

En esta rama se concentra la integración del código fuente del sistema desarrollado en Java bajo el patrón Modelo-Vista-Controlador (MVC), junto con la documentación actualizada, esquemas de base de datos, evidencias y artefactos de seguimiento producidos para la **Tercera Entrega**.

---

## Estructura del Repositorio - Tercera Entrega

### Código Fuente y Configuración (Raíz)

| Elemento | Descripción |
| :--- | :--- |
| [**`src/main/java`**](https://github.com/alesitaaguilarg/ProyectoDeFiscalia/tree/Tercera-Entrega/src/main/java) | Contiene el código fuente del proyecto en Java organizado bajo la arquitectura MVC (paquetes de modelos, controladores, vistas y conexión a base de datos). |
| [**`pom.xml`**](https://github.com/alesitaaguilarg/ProyectoDeFiscalia/blob/Tercera-Entrega/pom.xml) | Archivo de configuración de Apache Maven con las dependencias, plugins y parámetros de compilación del proyecto. |
